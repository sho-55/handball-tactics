# ハンド動き解説（きっかけシート）

ハンドボールのセットプレーを、駒が動くアニメーションで説明するページ。中学生の選手がスマホで見る想定。

- 公開ページ: https://sho-55.github.io/handball-tactics/
- 依存なしの静的サイト（HTML / CSS / JavaScript）。ビルド不要。

## 構成
```
index.html              セット一覧
tactic.html?id=06       再生ページ（共通）
js/engine.js            コート描画・補間・ステップ/分岐制御
js/app.js               再生ページのUI
js/glossary.js          用語ヘルプ
tactics/index.js        セット一覧の登録
tactics/NN-*.js         各セットのデータ（05 ユーゴ / 06 サイドユーゴ / 07 センターサイド / 08 CCダッポ）
SCRIPT_NN.md            各セットのアニメ台本表（指導者確認用。データから自動生成）
```

## セットを追加する
1. `tactics/NN-name.js` を 06 を参考に作る（`window.TACTICS["NN"] = {...}`）
2. `tactics/index.js` に1行追加する

### 使えるイベント
| type | 内容 | 主な項目 |
|---|---|---|
| move | 選手の移動（折れ線） | who, to:[[x,y],...] |
| pass | パス | from, to |
| fake | パスフェイク | from, to |
| shoot | シュート | who |
| block | ブロック/スクリーン（移動して着いたらバー表示） | who, to |
| zone | エリア強調 | rect:[x,y,w,h], label |
| note | コート上の注釈 | x, y, text |
| wait | 間を作る | (t, dur のみ) |

すべて `t`（開始秒）と `dur`（長さ秒）を持つ。同じ選手の move は重ねない。

### 左右反転
再生ページの「⇄ 左右反転」で、同じセットを鏡写し（右側から始動）にできる。データは片側だけ書けばよい。
x 座標は 20-x に、LW↔RW・LB↔RB・左n↔右n のラベルと解説文の「左/右」「LW/RW」「LB/RB」が自動で入れ替わる。
`tactic.html?id=06&mirror=1` で反転状態のリンクを共有でき、選択は端末に記憶される。

### 分岐の仕様
- 分岐は本線の `from` 秒時点の配置（関係ない選手も含む）から始まり、シュートで終わってその場で止まる
- 別の分岐を選ぶと、その分岐の `from` 時点まで巻き戻してから再生する
- 「次へ」は分岐を捨てて次ステップの本線へ。「前へ」は分岐中なら同じステップの本線に戻る
- 自動再生は本線のみ。分岐をタップすると自動再生は止まる

## 立体3Dの試作（pov-3d.html）

`pov-3d.html` はユーゴ（05）のRB専用の別ページ。スマホ縦画面を優先し、本線4ステップと最後の「アウト割り／PVパス／サイド落とし」の3分岐を収録。既存の `pov.html?id=05&pos=RB` から「3D試作」で開ける。

- 選手を自然な頭身に調整し、立体的なユニフォーム・襟・顔・靴・ボールの質感を追加。歩幅は移動距離と速度に連動し、停止時は支持足を床に接地。守備の膝の曲げ、キャッチの構え、パスの振りかぶりとフォロースルーを表現。姿勢は時刻から計算するためシークしても再現する。
- 加速・減速に合わせた前傾と踏ん張り、守備の横ステップ、腰を軸にした胸・肩のひねりを追加。RB目線ではキャッチ前の手の伸びと、パス後の腕のフォロースルーも表示する。
- 明るい学校の体育館、木の床、照明・影・ネット、ユニフォーム姿の立体選手。走る・構える・投げる姿勢は手続き的な簡易アニメーションであり、実選手のフォーム再現ではない。
- RBの位置・目の高さ1.6mにカメラを固定し、頭の揺れは加えない。保持中に手とボールを表示。既存の時刻付き視線データを使い、ドラッグ／矢印キーで周囲を確認できる。「視線を戻す」またはHomeで復帰。
- 学習モードでは判断の場面で停止し、ユーザーの「続き」操作を待つ。体験モードでは解説・注目表示・ミニマップを隠し、本線を連続再生。最後の判断では両モードとも自動停止し、3D画面下部に3択を表示。シュート後は「別の選択を試す／もう一度／最初から」を表示。
- ページ全体を一画面に固定し、再生・一時停止・前後・選択肢・シークを常設。音・速度・モード・視野幅・ステップ選択は画面内の「設定」に集約。効果音はWeb Audioの合成音（足音・ボール）で初期OFF。タブを離れると停止。端末のreduced-motion設定では終端の静止画に進む。
- データは `05-yugo.js` のコピーを使い、既存ページ・戦術軌道を変更しない。GKは元データに含まれないため追加していない。実機スマホの性能は端末に依存する。
- `js/court-3d.js` が体育館・人物・手の形状、`js/pov-3d.js` が描画と操作。既存 `PovView` の視線計算・判断停止と `TacticEngine` の状態計算を再利用。Three.js 0.170.0を `vendor/` にMITライセンス付きで同梱し、実行時のCDN・外部モデル・音声ファイルへの依存はない。
- WebGLが使えない場合は元のRB目線へのリンクを表示。通常のブラウザでHTTP(S)経由で開く。

検証: ローカルサーバー起動後、`python3 scripts/test_3d.py /tmp/handball-3d-qa`。PlaywrightのChromium（ヘッドレスのGPU制約を避けるSwiftShader）とWebKitで、スクロールなしの本線再生・全3分岐・終了後の再選択/再生・視線操作・判断停止/再開・設定・音・320px等の幅/横画面・reduced-motionを確認し、スクリーンショットを保存する。WebKit検証は実機iPhoneの検証を代替するものではない。

自動視線は実際の3D画面の縦横比と視野角を使い、ゴール全体とボール（半径を含む）が画面内に入るように向き・必要な視野角を調整する。元の視線の平滑化後に補正するため、受球途中でもボールを追える。カメラ近傍のパス・シュートは手元から出入りする描画とし、戦術の時刻・選手座標・ボール状態は変更しない。ドラッグなどで見回している間は手動操作を優先し、「視線を戻す」で自動構図に戻る。`python3 scripts/test_3d_framing.py` で通常版・反転版の本線と全分岐、受球の縦横画面をChromium/WebKitで検証する。

## 目線ビュー（pov.html、試作）
`pov.html?id=05&pos=RB` で、その選手の目の高さ（1.6m・視野角120°は仮値）から見た疑似3Dを表示する。
ステップ・分岐の再生は `tactic.html` と同じ `Player` を使い、描画だけ `js/pov.js` が足す（`Player.onRender` フック）。
右上の小さな図は上から見た位置と視野（黄色の扇）。左右反転も使える。反転すると RB の位置には元データの LB 役が来るので、`pos=RB&mirror=1` は「元データの `pov.LB` の視線データ」を RB 目線として表示する（ラベル・文中の左右は自動で入れ替わる）。反転版の視線データは元データの向きで書く（例: 元の右3枚目 → 反転表示では左3枚目）。

### データ（ステップ・分岐に任意で付ける）
```js
pov: { RB: { cues: [
  { t: 0.0, face: "CB", look: "CB", say: "CBが前を狙う", est: true },
  { t: 0.9 },                                  // face/look 無し = 既定ルール、吹き出しを消す
  { t: 0.7, stop: true, look: ["R2", "R1"], say: "右2枚目・右1枚目の位置を見る" },
] } }
```
| 項目 | 意味 |
|---|---|
| `t` | ステップ内の秒。cue は次の cue まで有効 |
| (パスの `kind`) | `actions` のパスに `kind: "bounce"`(バウンド) / `"lob"`(頭上) を付けると、上から図ではラベル、目線ではボールの高さが変わる。パスの0.6秒前から届くまで、出し手→受け手のコースを緑の帯で表示（DFがコース上なら赤）。基準は普通のパス 1.0m、バウンド/頭上 0.7m。`scripts/check_lanes.js` で全パスを検査できる |
| `face` | 顔の向き。選手ID / 選手IDの配列（その中間を向く） / `"GOAL"` / `"BALL"` / `[x,y]`。省略時は「他人が持っている間はボール、自分が持ったらゴール」 |
| `look` | 黄色の点線と「見る」で強調する相手（複数可）。視野の外なら画面端のチップで示す |
| `say` | 吹き出し。`est: true` でシートに無い推定として「仮」バッジが付く（台本表にも ※推定） |
| `stop: true` | その秒で一時停止して「〇〇を見る」を出す。タップで続き。自動再生中は 1.5 秒後に自動で続く |

顔の向きは「ボール（自分が持っていない時）とゴールが常に視野に入る」範囲に丸めたうえで、直近 0.5 秒の目標を平均した「t の純関数」なので、速さや操作順で変わらない。ステップの先頭では前ステップの末尾（分岐なら本線の分岐点前）を参照して首が飛ばないようにしている。
目線ページでは、その目線の `pov` を持つ分岐だけチップに出す。`tactics/index.js` の `pov: ["RB"]` で、上から図のページに目線ページへのリンクが出る。
