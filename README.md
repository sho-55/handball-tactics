# ハンド動き解説（きっかけシート）

ハンドボールのセットプレーを、駒が動くアニメーションで説明するページ。中学生の選手がスマホで見る想定。

- 公開ページ: https://sho-55.github.io/handball-tactics/
- 依存なしの静的サイト（HTML / CSS / JavaScript）。ビルド不要。

## 構成
```
index.html              セット一覧
tactic.html?id=06       再生ページ（共通）
js/engine.js            コート描画・補間・ステップ/分岐制御
js/app.js               再生ページのUI
js/glossary.js          用語ヘルプ
tactics/index.js        セット一覧の登録
tactics/NN-*.js         各セットのデータ（05 ユーゴ / 06 サイドユーゴ / 07 センターサイド / 08 CCダッポ）
SCRIPT_NN.md            各セットのアニメ台本表（指導者確認用。データから自動生成）
```

## セットを追加する
1. `tactics/NN-name.js` を 06 を参考に作る（`window.TACTICS["NN"] = {...}`）
2. `tactics/index.js` に1行追加する

### 使えるイベント
| type | 内容 | 主な項目 |
|---|---|---|
| move | 選手の移動（折れ線） | who, to:[[x,y],...] |
| pass | パス | from, to |
| fake | パスフェイク | from, to |
| shoot | シュート | who |
| block | ブロック/スクリーン（移動して着いたらバー表示） | who, to |
| zone | エリア強調 | rect:[x,y,w,h], label |
| note | コート上の注釈 | x, y, text |
| wait | 間を作る | (t, dur のみ) |

すべて `t`（開始秒）と `dur`（長さ秒）を持つ。同じ選手の move は重ねない。

### 左右反転
再生ページの「⇄ 左右反転」で、同じセットを鏡写し（右側から始動）にできる。データは片側だけ書けばよい。
x 座標は 20-x に、LW↔RW・LB↔RB・左n↔右n のラベルと解説文の「左/右」「LW/RW」「LB/RB」が自動で入れ替わる。
`tactic.html?id=06&mirror=1` で反転状態のリンクを共有でき、選択は端末に記憶される。

### 分岐の仕様
- 分岐は本線の `from` 秒時点の配置（関係ない選手も含む）から始まり、シュートで終わってその場で止まる
- 別の分岐を選ぶと、その分岐の `from` 時点まで巻き戻してから再生する
- 「次へ」は分岐を捨てて次ステップの本線へ。「前へ」は分岐中なら同じステップの本線に戻る
- 自動再生は本線のみ。分岐をタップすると自動再生は止まる

`python3 -m http.server 8765` で起動し、Playwright のテスト（scratchpad の test.py）で以下を確認している。
375px 幅で横スクロールなし / 全分岐が最後まで再生できる / 前後操作で配置がずれない / 速度によらず最終配置が同じ / 自動再生ボタン連打で二重再生しない / 全用語の説明が開閉できる / 「動きを減らす」設定で即時に最終配置を表示

## 目線ビュー（pov.html、試作）
`pov.html?id=05&pos=RB` で、その選手の目の高さ（1.6m・視野角110°は仮値）から見た疑似3Dを表示する。
ステップ・分岐の再生は `tactic.html` と同じ `Player` を使い、描画だけ `js/pov.js` が足す（`Player.onRender` フック）。
右上の小さな図は上から見た位置と視野（黄色の扇）。左右反転は目線ページでは使えない（保存設定も復元しない）。

### データ（ステップ・分岐に任意で付ける）
```js
pov: { RB: { cues: [
  { t: 0.0, face: "CB", look: "CB", say: "CBが前を狙う", est: true },
  { t: 0.9 },                                  // face/look 無し = 既定ルール、吹き出しを消す
  { t: 0.7, stop: true, look: ["R2", "R1"], say: "右2枚目・右1枚目の位置を見る" },
] } }
```
| 項目 | 意味 |
|---|---|
| `t` | ステップ内の秒。cue は次の cue まで有効 |
| `face` | 顔の向き。選手ID / 選手IDの配列（その中間を向く） / `"GOAL"` / `"BALL"` / `[x,y]`。省略時は「他人が持っている間はボール、自分が持ったらゴール」 |
| `look` | 黄色の点線と「見る」で強調する相手（複数可）。視野の外なら画面端のチップで示す |
| `say` | 吹き出し。`est: true` でシートに無い推定として「仮」バッジが付く（台本表にも ※推定） |
| `stop: true` | その秒で一時停止して「〇〇を見る」を出す。タップで続き。自動再生中は 1.5 秒後に自動で続く |

顔の向きは直近 0.5 秒の目標を平均した「t の純関数」なので、速さや操作順で変わらない。ステップの先頭では前ステップの末尾（分岐なら本線の分岐点前）を参照して首が飛ばないようにしている。
目線ページでは、その目線の `pov` を持つ分岐だけチップに出す。`tactics/index.js` の `pov: ["RB"]` で、上から図のページに目線ページへのリンクが出る。
